# Каталог, этапы задач и справка настроек — 26–27.09.2026

## Изменения

- В списке мест и на странице места добавлено раскрытие вещей. До открытия список не запрашивается, после открытия показаны миниатюры, остатки и ссылки. Вложенные места включаются отдельно. Использован существующий API contents; изменения учёта и LLM не нужны.
- Состояние выбора перенесено из пересоздаваемого результата поиска на уровень страницы Items. Map хранит ID и снимок карточки. Выбранные карточки закреплены над выдачей, исключены из дублей; новые поиски, пустые результаты и сетевые ошибки не теряют набор. Массовая операция читает свежие версии всех выбранных вещей. Выбор очищается явно или после успеха, не сохраняется после ухода со страницы/смены инвентаря.
- В списке задач и детализации показаны миниатюра и SVG-кольцо. Равные секции различаются цветом стадии; текущий этап выделен, ошибка/остановка/пропуск не объявляются успехом. Кольцо не использует длительность, percent или ETA. На странице задачи есть легенда; доступное текстовое описание передаёт все состояния. Сохранена поддержка reduced motion. Компонент также используется в незавершённых добавлениях каталога.
- Справка Help открывается наведением, фокусом и нажатием, закрывается Escape/наружным нажатием и не переключает соседние флажки. Окно ограничено экраном и прокручивается. Input/Select принимают дополнительный info без изменения остальных форм. Справка покрывает 68 административных и 4 пользовательских параметра; для недоступных функций объяснена недоступность, для доступных — назначение и последствия. Технические диапазоны/default/apply_mode берутся из действующей схемы API. Добавлены пояснения профиля, правил сроков, моделей, очередей, GPU и очистки.
- Исправлен ввод nullable-настроек: пустой вариант возвращает null, включая денежный предел; для nullable enum есть «Не задано». Справка денежного ограничения честно описывает UNKNOWN_MODEL_PRICE при отсутствии достоверной оценки стоимости.

Промпты, серверный pipeline, лимит одновременных вызовов и хранилища не изменены. Приватность описана по фактическим правилам: предпочтение облака не разрешает внешнюю обработку документов, чувствительных или сомнительных материалов.
