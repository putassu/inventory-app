# ADR-002: доверенный audio endpoint и восстанавливаемый поиск

Владелец явно подтвердил, что `https://as.rsmu.ru/litellm` находится в его доверенном контуре и разрешил отправлять туда фотографии и записи из `tests/cases`. Поэтому `local-gemma-4-e4b` подключена отдельным локальным audio adapter. Имя протокола LiteLLM не определяет границу доверия. Внешний адаптер и его разрешения остаются отдельными.

Проверен OpenAI-совместимый `input_audio` WAV, включая синтетическую тишину и реальную запись. Совместный audio+image запрос не нужен: сначала аудио, затем прежние gatekeeper/VLM промпты с одним коллажем. Имена моделей и endpoint references входят в snapshot задачи. Секреты snapshot не содержит. Все локальные вызовы и эмбеддинги используют общий GPU slot, даже если audio endpoint физически расположен на другом доверенном сервере: это консервативный профиль низкой параллельности.

Для sparse retrieval выбран детерминированный BM25 term-frequency saturation с k1=1.2, b=.75 и фиксированной опорной длиной 128 токенов; Unicode-токенизация нормализует ё/е. Qdrant вычисляет IDF, dense BGE-M3 использует 1024 измерения, объединение — RRF. Это фиксированная версия индекса, а не утверждение о точном совпадении с corpus-average BM25/FastEmbed. Такой выбор не требует загрузки второго локального sparse encoder. См. [официальный hybrid query API Qdrant](https://api.qdrant.tech/v-1-18-x/api-reference/search/query-points).

Перестройка создаёт новую физическую коллекцию и проверяет её версии перед сменой alias. Индексные данные никогда не выдаются без hydration PostgreSQL; удалённая или чужая карточка не появляется даже при старой точке Qdrant. При недоступном индексе сохраняется поиск по подтверждённым названиям, alias, кодам и PostgreSQL FTS.

Первый неудачный запрос массового удаления старых директорий был отклонён автоматической проверкой. Использован более безопасный способ: проверенные абсолютные пути перенесены в игнорируемый `data/legacy-source-20260917`. Они исключены из импортов и поставки, исходные незакоммиченные файлы остаются доступными для сверки. Рабочие данные и история Git не затрагивались.
